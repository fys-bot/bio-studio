# AI 辅助开发与 Review 记录

## 使用方式

本项目使用 Codex 辅助完成产品逆向、交互设计、代码实现和问题排查。提供给 AI 的上下文包括：作业文档、Biomni 任务页截图、当前仓库结构、运行日志和验收目标。

## AI 参与内容

- 逆向 Biomni 的项目导航、对话时间线、澄清问题、工具抽屉和任务状态；
- 设计 RNA-seq 主场景和“对话 → 澄清 → 审批 → 执行 → 结果”状态机；
- 实现 Next.js 页面、鉴权 API、任务 Store、SSE 事件、代码流和 Artifact；
- 实现响应式布局、分栏拖拽、工具抽屉、3D 结构预览和工作流画布交互；
- 根据浏览器截图排查中屏空白、端口占用和 Next.js 缓存问题。

## 人工 Review 与修正

- 发现首版偏向通用深色控制台后，重新对照 Biomni，将产品改为对话优先；
- 发现中屏右侧空白由 React 内联网格覆盖媒体查询造成后，改为视口状态驱动列数；
- 发现澄清表单与 Biomni 的对话卡片不一致后，改为分步单选卡片；
- 发现输入框只有视觉效果后，补充受控输入、Enter 发送和 Agent 确认回复；
- 发现 `Cannot find module './682.js'` 后，清理构建缓存并增加 Node 20 版本约束。

## 验证方式

- `npm run typecheck`；
- `npm run build`（推荐 Node.js 20 LTS）；
- 手工验证澄清、审批、失败、重试、取消、抽屉、画布拖拽和移动端布局。

AI 生成的代码不直接视为正确实现，最终行为以人工 Review、类型检查、构建和浏览器验证为准。
