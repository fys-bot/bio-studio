# BioFlow Studio 后续待办工作流

## 目标

把当前“可运行的演示型科研 Agent”继续收口为“可配置、可解释、可恢复、便于代码 Review 的面试 Demo”。优先保证核心演示链路完整，再补真实数据能力和工程结构，不以堆页面数量为目标。

## 当前基线

- 当前完成度：约 92%（按需求文档的面试作业评价口径）。
- 已完成：产品逆向分析、任务状态机、鉴权 API、服务端 Mock Runner、SSE、失败/重试/取消、工作流画布、RAG Trace、AI 代码流、结果血缘、可交互 3D 结构预览、CSV/TSV 真实解析、粒子化加载、配置面板与统一质量门禁。
- 当前演示入口：`npm run dev`，默认访问 `http://127.0.0.1:3000`。
- 当前默认场景：bulk RNA-seq 差异表达分析，默认保留“设计矩阵失败 → 局部修复 → 完成”的演示路径。

## P0 面试演示闭环

### P0-1 真实演示脚本走通

目标：保证 5～8 分钟内能稳定展示完整价值链路。

演示路径：

```text
打开粒子加载页
→ 输入科研问题
→ 查看 Agent Trace
→ 完成四步澄清
→ 生成并审批分析计划
→ 展开工作流画布
→ 启动运行
→ 看到 RAG 事件和代码流
→ 触发失败
→ 查看证据与失败原因
→ 局部重试
→ 查看火山图、代码、结果血缘和 3D Artifact
```

验收标准：

- 任何一步刷新页面后，任务状态仍能从服务端恢复。
- 失败、重试、取消三个分支都能在 30 秒内演示。
- 所有关键按钮都有明确的视觉、Toast、抽屉或状态反馈。
- 演示数据每次重置后保持确定性，不依赖外网或真实 Token。

### P0-2 多分辨率最终验收

验收尺寸：1440×900、1280×800、1024×768、768×1024、390×844。

重点检查：

- 中屏不出现内容被挤压、遮挡或空白区域。
- 右侧 Inspector 在中屏和移动端切换为抽屉。
- 弹窗可以点击空白处和 Esc 关闭。
- 画布不会遮挡对话输入框。
- 粒子加载动画在低宽度下不出现横向溢出。

阶段不能只验证本阶段新增功能。每个 P0/P1/P2/P3 阶段结束时，都必须执行一次全量回归：

- 核心用户路径：提问、澄清、生成计划、审批、运行、失败、重试、取消、刷新恢复。

- 视觉与设备：1440、1280、1024、768、390 五种视口，检查溢出、遮挡、白屏和弹层关闭。
- 工程质量：TypeScript、格式、构建、smoke、Git diff 和中文 CHANGELOG。

阶段验收记录必须包含：

1. 本阶段新增功能清单。

任何一项核心回归失败，阶段状态保持“进行中”，不能直接标记完成或提交阶段结论。
