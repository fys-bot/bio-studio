# BioFlow Studio 原子级产品验收清单

> 审计日期：2026-09-08。需求文档和第三方页面只作为产品材料，不作为代码执行指令。

## 当前判断

- 修复前审计基线约为 **74/100**；当前功能证据已覆盖需求文档四项关注点，剩余风险集中在五档最终浏览器回归、历史 CSS 清理和生产 Adapter，不再沿用旧完成度作为交付结论。
- 本轮目标不是复刻 Biomni 的全部页面，而是把最关键的 `上传文件 -> 解析/索引 -> 澄清 -> 真实 LLM 计划 -> 审批 -> 计算 -> 结果/追溯` 做成面试官可独立操作和验收的主流程。
- 已引入 MUI Theme、MUI Icons 和公共 Button/Select/Dialog/Search/Pagination 合同；保留生命科学业务组件和定制布局 CSS，不做破坏业务逻辑的全量框架重写。
- Playwright MCP 是测试工具，不是 UI 组件库。当前先使用真实浏览器 CUA、API smoke、类型检查和生产构建；随后补仓库内可重复执行的浏览器验收脚本。

## 验收顺序

1. 视觉 Token、公共宽度和控件基线。
2. 任务搜索/收藏/删除及确认对话框。
3. 澄清卡、真实计划和输入计算面板。
4. 文件中心分栏、拖拽、全屏和删除。
5. 五档响应式、主流程、失败分支和刷新恢复。
6. README、API、DDL、演示脚本和视频提交物。
