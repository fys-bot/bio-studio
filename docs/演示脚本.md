# BioFlow Studio 面试演示脚本（约 6 分钟）

## 1. 产品定位（30 秒）

说明这是面向生命科学研究的 Agent 工作区，不是普通聊天机器人。它把模糊科研问题转成可审查、可干预、可恢复的分析任务。

## 2. 输入问题（45 秒）

展示 RNA-seq 问题已进入对话时间线，说明 Agent 会先检查项目文件，再确认实验设计。

## 3. RAG 与澄清（60 秒）

点击“查看执行轨迹”，展示识别意图、检索文件、证据重排和参数绑定。然后依次选择数据格式、比较方案、物种和交付物，强调每个选项会影响后续分析路径。

## 4. 计划审批（45 秒）

生成分析计划，展示六个步骤和审批按钮。强调 Agent 不会绕过用户直接执行高成本任务。

## 5. 工作流画布（60 秒）

点击“分析计划”展开画布，演示节点拖拽、空白区域平移、滚轮缩放、重置和 Shift+点击连线。

## 6. 失败与恢复（60 秒）

运行工作流，展示 `condition` 字段缺失导致节点失败；打开工具抽屉查看证据和日志，点击局部重试，展示代码流和结果 Artifact。

## 7. 工具抽屉与多端（40 秒）

依次打开待办、结果、计算和笔记；缩窄窗口展示抽屉和底部工具坞，点击遮罩或按 Esc 关闭。

## 8. 工程说明（30 秒）

说明服务端 HMAC Cookie 鉴权、Origin 校验、本地持久化、SSE 事件和 Mock Runner；真实模型可替换 Agent Adapter，不提交真实 Token。
