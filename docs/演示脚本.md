# BioFlow Studio 面试演示脚本（约 7 分钟）

## 1. 产品定位（30 秒）

说明这是面向生命科学研究的 Agent 工作区，不是普通聊天机器人。它把模糊科研问题转成可审查、可干预、可恢复的分析任务。

## 2. 输入问题（40 秒）

展示 RNA-seq 问题已进入对话时间线，说明 Agent 会先检查项目文件，再确认实验设计。

## 3. RAG 与真实文件解析（75 秒）

点击“查看执行轨迹”，展示识别意图、检索文件、证据重排和参数绑定。打开“上传”，选择 `demo-data/sample_metadata.tsv`，展示 6 个样本、4 个字段、1 个缺失值和 `condition` 分组建议。点击“应用到分析上下文”，强调 Agent 不只回答问题，还能把数据结构转成下一步可执行参数。然后补完数据格式、比较方案、物种和交付物。

## 4. 计划审批（45 秒）

生成分析计划，展示六个步骤和审批按钮。强调 Agent 不会绕过用户直接执行高成本任务。

## 5. 工作流画布与持久化（65 秒）

点击“分析计划”展开画布，演示节点拖拽、空白区域平移、滚轮缩放、重置和 Shift+点击连线。放大到 110%，等待工具栏显示“已自动保存”，点击“保存版本”，刷新页面后再次打开画布，展示版本号和布局仍然存在。

## 6. 失败与恢复（60 秒）

运行工作流，展示 `condition` 字段缺失导致节点失败；打开工具抽屉查看证据和日志，点击局部重试，展示代码流和结果 Artifact。

## 7. 结果、代码与 3D（45 秒）

查看代码流式输出，说明 `code.delta` 事件如何逐字符产生 Python 分析代码；再查看火山图、候选基因、Artifact 血缘、Markdown 报告和 3D 结构残基联动。

## 8. 工具抽屉与多端（35 秒）

依次打开待办、结果、计算和笔记；缩窄窗口展示抽屉和底部工具坞，点击遮罩或按 Esc 关闭。

## 9. 工程说明（35 秒）

说明服务端 HMAC Cookie 鉴权、Origin 校验、文件结构摘要、布局版本、本地持久化、SSE 事件和 Mock Runner；真实模型可替换 Agent Adapter，真实数据库、队列、对象存储和 Mol* 只需要替换文档中标出的边界，不提交真实 Token。

## 面试官追问时的三个回答

1. **为什么不是普通聊天页面？**
   因为每个回答都会落到澄清、证据、参数、工作流节点或 Artifact，用户可以审批、干预和恢复，而不是只能重新提问。
2. **Mock 数据如何替换成真实能力？**
   页面依赖领域类型和 API 协议，不依赖 Mock 实现；将 Runner 换成队列和 Agent Gateway，将 Store 换成数据库即可保留前端交互。
3. **如何保护生命科学数据？**
   写接口有 HttpOnly 会话和 Origin 校验；上传文件只在服务端做结构摘要，原始单元格不返回前端，也不放进客户端日志。
